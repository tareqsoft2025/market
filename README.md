# إدارة السوبر ماركت (Market)

تطبيق Android لإدارة محل سوبر ماركت. يعمل بدون إنترنت، والبيانات محفوظة على الجهاز، ويتحدث من GitHub مع الحفاظ على البيانات.

## الوحدات

| الوحدة | ما تقوم به |
|---|---|
| **المخزن والأصناف** | إضافة الأصناف (باركود، تصنيف، وحدة، سعر شراء وبيع، حد إعادة الطلب)، توريد بضاعة، جرد وتسوية، كرت الصنف (كل حركة على الكمية) |
| **نقطة البيع** | مسح الباركود (كاميرا أو قارئ USB/بلوتوث)، بحث بالاسم، تعديل الكمية والسعر، خصم على الفاتورة، دفع نقدي / تحويل بنكي / آجل |
| **الفواتير والمردودات** | عرض الفواتير حسب اليوم والبحث، مردود جزئي أو كلي مع توزيع الخصم، إرجاع للمخزن أو تسجيل كتالف، رد المبلغ نقداً أو بتحويل أو خصمه من حساب العميل |
| **التحصيلات والتحويلات** | مراجعة التحويلات البنكية (تأكيد / رفض)، حركة الصندوق اليومية، النقد المتوقع في الدرج |
| **العملاء والديون** | رصيد كل عميل، تحصيل دفعات، سجل الفواتير والدفعات |
| **التقارير** | يومي أو من بداية الشهر: المبيعات، المردودات، الصافي، التكلفة، مجمل الربح، حسب طريقة الدفع، الأكثر مبيعاً |
| **الإعدادات** | اسم المحل والعملة، التحقق من التحديثات، نسخ احتياطي واسترجاع |

## التقنية

- Kotlin + Jetpack Compose (واجهة عربية من اليمين لليسار)
- Room (SQLite) لقاعدة البيانات المحلية
- GitHub Actions لبناء التطبيق ونشر الإصدارات

## كيف يعمل التحديث دون حذف البيانات

1. كل إصدار له **نفس اسم الحزمة** `com.tareqsoft.market` و**نفس مفتاح التوقيع**، فيثبّته أندرويد كتحديث ويحتفظ بالبيانات.
2. التطبيق يفحص [Releases](https://github.com/tareqsoft2025/market/releases) عند الفتح، ويعرض "يتوفر إصدار جديد". يضغط المستخدم "تنزيل وتثبيت" ثم "تثبيت".
   - في أول تحديث فقط يطلب أندرويد السماح للتطبيق بتثبيت التحديثات.
3. أي تغيير في جداول قاعدة البيانات يكون عبر **Migration** (راجع `MarketDatabase.kt`). التطبيق لا يحذف البيانات عند تغيير الجداول أبداً.

## نشر إصدار جديد

```bash
git tag v1.0.1
```

```bash
git push origin v1.0.1
```

يبني GitHub Actions ملف APK موقّعاً وينشره في Releases، وتظهر رسالة التحديث على الأجهزة.
رقم الإصدار يجب أن يكون أكبر من السابق دائماً.

## مفتاح التوقيع (مرة واحدة فقط)

أضف هذه القيم في: **Settings ← Secrets and variables ← Actions ← New repository secret**

| الاسم | القيمة |
|---|---|
| `MARKET_KEYSTORE_BASE64` | محتوى ملف `market-release.jks` بصيغة base64 |
| `MARKET_KEYSTORE_PASSWORD` | كلمة مرور الملف |
| `MARKET_KEY_ALIAS` | `market` |
| `MARKET_KEY_PASSWORD` | كلمة مرور المفتاح |

> ⚠️ احفظ ملف المفتاح وكلمات المرور في مكانين آمنين. إذا فُقد المفتاح فلن تتمكن الأجهزة من التحديث أبداً، وسيلزم حذف التطبيق (وضياع البيانات).
> لا ترفع ملف المفتاح إلى المستودع (ملف `.gitignore` يمنع ذلك).

## نسخة الاختبار

كل push يبني نسخة debug تجدها في تبويب **Actions ← Build ← Artifacts**.
تُثبَّت كتطبيق منفصل (`com.tareqsoft.market.debug`) فلا تؤثر على بيانات المحل.

## الرفع للإنترنت (مرحلة لاحقة)

القاعدة مجهزة للمزامنة: كل سجل له معرّف UUID وتاريخ `updatedAt`، ولكل جهاز معرّف خاص. تُضاف لاحقاً خدمة سيرفر ترفع السجلات المعدّلة بعد آخر مزامنة.

## أفكار للتطوير

- طباعة الإيصال على طابعة بلوتوث
- الموردون وفواتير الشراء
- صلاحيات الموظفين برقم سري وإغلاق الوردية
- تصدير التقارير إلى Excel
- المزامنة مع السيرفر ولوحة تحكم ويب
